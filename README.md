# Истоки

Бесплатный поиск документов о предках: https://isradata.vercel.app/ (русский) и `/en/` (английский).
Статический сайт без сборки, размещён на Vercel. Запросы к части баз идут через воркер на Cloudflare.

## Что где лежит

| Файл | Что это |
| --- | --- |
| `config.js` | Настройки: адрес воркера, ключи баз, счётчики статистики, реклама |
| `index.html`, `en/index.html` | Главные страницы: тексты, SEO и FAQ на своём языке |
| `assets/app.js` | Поиск и все переводы интерфейса (`I18N`), общий для двух главных страниц |
| `assets/main.css` | Оформление главных страниц |
| `assets/site.js` | Статистика для всех страниц |
| `guides/`, `about/`, `privacy/` и то же в `en/` | Гайды и служебные страницы |
| `sitemap.xml`, `robots.txt`, `404.html`, `vercel.json` | Служебные файлы |

Новую функцию или перевод интерфейса добавляйте в `assets/app.js`: она сразу появится на обеих главных страницах.

## Настройки в `config.js`

- `PROXY_URL` — адрес воркера, без слэша в конце.
- `EUROPEANA_KEY`, `NLI_KEY`, `DPLA_KEY` — ключи баз. Они видны всем посетителям, поэтому используйте только бесплатные ключи.
- `YANDEX_METRIKA_ID`, `GA4_ID` — счётчики статистики; `0` или пустая строка отключают счётчик. Если меняете сервис, обновите `privacy/index.html` и `en/privacy/index.html`.
- `FEEDBACK_URL` — ссылка «Нашли документ? Расскажите», например Google Форма.
- `NARA_ENABLED` — `true`, когда в воркер добавлен `NARA_KEY`.
- `FOOTER_ADS` — рекламные блоки в подвале.

## Поиск и адрес страницы

Данные поиска не хранятся в адресной строке, чтобы имена не попадали в статистику. Кнопка «Ссылка» копирует полный адрес с запросом, а такие адреса открываются как обычно.

## Новый гайд

1. Скопируйте папку похожего гайда и поменяйте текст, `title`, `description`, `canonical` и `hreflang`.
2. Добавьте адрес в `sitemap.xml`, в список на странице гайдов и в подвал главной страницы.

## Статистика

Сейчас работает Яндекс Метрика (`YANDEX_METRIKA_ID`). Чтобы подключить Google Analytics 4, создайте поток данных в analytics.google.com и впишите его идентификатор вида `G-XXXXXXXXXX` в `GA4_ID`.

## Ключи баз

Бесплатные ключи выдают сами сервисы: Europeana (pro.europeana.eu), Национальная библиотека Израиля (api.nli.org.il/signup) и DPLA (dp.la). Если поле пустое, источник скрывается; для библиотеки Израиля вместо него используется гостевой ключ с лимитом запросов.
